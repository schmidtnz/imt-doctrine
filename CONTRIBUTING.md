# Contributing

Use the "Edit this page" link on any page to propose a change; GitHub opens a pull request for you. Describe what you changed and why in the pull request. If you change the meaning of a principle, concept, guideline, process or form, bump its `version` number. Doctrine pages (Parts 1, 2, 3.1–3.2) need approval from the review group; guidance and forms need one approval from any reviewer. If you'd rather not edit, start a Discussion instead.
