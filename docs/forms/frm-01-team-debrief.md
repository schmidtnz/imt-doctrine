# FRM-01 Team debrief (search effort evaluation)

Debrief the whole team in person where possible: one person asks (operations), one records (intelligence). Don't let teams fill this in themselves.

| Field | Notes |
|---|---|
| Team, task and segment | |
| Time in and out | |
| Route and coverage | Annotated map and GPS track |
| Technique and spacing | As tasked, or what changed and why |
| Conditions | Vegetation, visibility, weather, terrain |
| Clues | What, where, when; photographed and preserved? |
| Hazards found | Pass to the safety function |
| POD per searcher | Rating and number; average them |
| What limited detection | Fatigue, distractions, radio issues, terrain |
| Recommendations | Re-search, other resources, new areas |
