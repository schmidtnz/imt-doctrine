# CON-15 The initial response process

The initial response begins straight after notification and follows pre-determined actions guided by the {doc}`Bike Wheel <con-14-bike-wheel>`. Its length depends on the size and complexity of the area, not a fixed time.

IMT managers need a process they can repeat without reference material. The mnemonic is **{term}`MMISSI TD`**:

1. **M**issing person report: initial details, medical, equipment, intentions.
2. **M**ap: terrain analysis, hazards, LPB search area, travel time and distance, planning points.
3. **I**nformation collection plan: build the profile, fill gaps, assign enquiries.
4. **S**cenario: quick, obvious scenarios.
5. **S**earch urgency: confirm the initial assessment still holds.
6. **I**ncident action plan: set objectives with the Bike Wheel.
7. **T**ask: from the objectives; preserve the planning point and clues; contain.
8. **D**ebrief: gather intelligence and POD.

Repeat steps 6–8 until the initial response objectives are met. The step-by-step version is {doc}`/part-3/3-4-processes/prc-01-initial-response`.

:::{note}
How urgent cases bypass the sequence, and how steps run in parallel, is still being worked through.
:::
