# CON-09 Lost and missing person behaviour

Lost person behaviour ({term}`LPB`) research, built from large international incident databases, moves initial planning from instinct to data. It lets an IMT set objectives and send resources to the most likely places first, when little is known about the subject. It is a tool, not the answer.

Apply it with judgement:

- The data is aggregated. Specific knowledge of this subject (fitness, injury, state of mind, intentions) can outweigh it.
- Local SAR history matters: subjects cluster where terrain and common decision errors take them.
- Check the **ecoregion** and the **sample size** (n) behind each figure; small samples are less reliable.
- Choose the **subject category** (for example hiker, child, despondent, dementia) using the category hierarchy; several may need considering.
- Use the category's **investigative questions** and **initial tasks**.
- Apply the category tables to the search area: distance travelled, elevation change, mobility, dispersion, find location, scenarios, track offset and survivability.

{{ org }} runs dedicated training on applying LPB.
