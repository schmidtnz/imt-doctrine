# PRN-05 Proactive planning and readiness

IMTs pre-plan for likely events in predictable or repeat locations, and practise those plans. Every operation should have a suitably trained and resourced IMT. Never assume an operation will be over quickly: set up the team and processes as if it will be protracted.

**In short:** pre-plan to improve efficiency, and resource the IMT properly.
