# PRC-03 Notification and on-scene coordination

1. Reports go to the Coordinating Authority, which becomes incident controller.
2. The controller assesses scale, urgency and likely resources, ideally with an IMT rather than alone.
3. The Coordinating Authority engages {{ org }} for field teams, an IMT, or both.
4. On-scene coordination:
   - If RCCNZ engages {{ org }} without Police, a {{ org }} response manager is assigned as on-scene coordinator ({term}`OSC`).
   - If Police are involved and a {{ org }} IMT is set up, Police can take the OSC role.

:::{note}
The on-scene coordinator arrangements are being verified with the Coordinating Authorities.
:::
