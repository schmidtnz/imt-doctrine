# CON-07 Phases of a land search and rescue operation

An operation is a continuum, but each phase needs different thinking:

1. **Initial response ({term}`IR`)**: pre-determined actions based on lost person behaviour and the {doc}`Bike Wheel model <con-14-bike-wheel>`; CIMS functions applied informally and scaled to need.
2. **Extended search planning ({term}`ESP`)**: starts if the initial response doesn't find the subject. Planning shifts from the statistical subject to *this* subject, using scenarios, consolidated intelligence and methodical searching of probable areas.
3. **Rescue (known location)**: can start at any point when the subject is found, or as a stand-alone operation, for example a beacon activation.

Notification isn't a phase as such; it usually sits with a Coordinating Authority.

Intelligence is the fuel. Without enough focus on collecting and analysing it, a search gets stuck in the initial response, tasking resources reflexively with no evidence to prefer one place over another. Move to extended search planning as the initial response objectives are completed, and resource intelligence from the start so the transition is smooth.

:::{note}
The draft uses several names for the second phase and differs on whether "operational conclusion" is a fourth phase. This site uses *extended search planning* throughout.
:::
