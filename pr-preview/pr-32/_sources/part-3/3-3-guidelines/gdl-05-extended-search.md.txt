# GDL-05 Extended search planning phase

Move to extended search planning as the initial response objectives are completed; start planning before they finish so the transition is seamless.

| Step | Guideline |
|---|---|
| Review the IR | Map areas searched, clues and POD. Check paperwork. Identify gaps in intelligence and coverage, and whether re-searching with other techniques would help. |
| Search area | Move from circles to shapes: bound the area by bluffs, rivers, ridges and corridors, using the subject's profile, capability, equipment and clues. |
| Scenarios | Present all intelligence to the IMT first. Test each scenario against the facts, terrain and LPB. Record each on a scenario recording sheet and map it as a region. |
| Regions | Aim for about 6–10, mixing scenario and geographical regions. |
| Weighting | Use the {doc}`scenario weighting sheet </forms/frm-02-scenario-weighting>` (option A) or ACH (option B). Write the weights on the map. |
| Segments | Segment the top one to three regions; weight segments using the same scenario. |
| Task and debrief | Task the highest segments; debrief whole teams for POD. |
| Recalculate | Reduce segment weights by POD. Re-search with a different resource, direction or timing, or move on. |

You will never reach 100 %. Deciding when to move on is a judgement informed by the numbers and the quality of the POD.
