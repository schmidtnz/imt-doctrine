# 3.6 Capability and resources

The doctrine supports existing national doctrine such as {term}`CIMS`. To deliver consistent practice, all sector partners need to agree on it as the baseline, then refine it over time.

Beyond process, the draft identifies four enablers that need sector-wide commitment:

1. consistent national call-out and engagement procedures
2. an interoperable mapping tool
3. an interoperable incident management system
4. communication protocols, processes and resources.

Together these support activation and a common operating picture at local, regional and national level, and should extend to working alongside civil defence.
