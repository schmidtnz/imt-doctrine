# Figures

Diagrams of four ideas from Part 3, drawn for this demonstration from the condensed text, and two logos as examples of raster images. The diagrams aren't the draft's own figures.

:::{note}
Diagrams are SVG files next to this page, so changes to them are reviewed in a pull request like text; the PDF build converts them. Photos and logos are PNG or JPG files, used as they are. Figures are numbered automatically and can be cross-referenced: the search planning loop is in {numref}`fig-esp-cycle`.
:::

## Levels of the doctrine

```{figure} hierarchy.svg
:name: fig-hierarchy
:alt: Five stacked levels, principles, concepts, guidelines, processes and forms, each deriving from the one above. Principles and concepts are the doctrine tier; the rest are the guidance tier. A dashed arrow from forms back up to principles shows double-loop learning.

The levels this site uses, each deriving from the one above, and the review tier for each ({doc}`CON-01 </part-3/3-1-concepts/con-01-hierarchy>`). Lessons from operations flow back up and can change any level.
```

## Phases of an operation

```{figure} phases.svg
:name: fig-phases
:alt: Initial response leads into extended search planning once its objectives are completed. Rescue runs underneath both phases.

The three phases ({doc}`CON-07 </part-3/3-1-concepts/con-07-phases>`). Rescue can start whenever the subject is found.
```

## The Bike Wheel model

```{figure} bike-wheel.svg
:name: fig-bike-wheel
:alt: A bicycle wheel whose hub, spokes, reflectors, rim with rocks, a stick caught in the spokes, and frame are each labelled with an initial response objective.

Each part of the wheel is an initial response objective ({doc}`CON-14 </part-3/3-1-concepts/con-14-bike-wheel>`). A schematic only: no distances are shown, and attribution of the model is still being checked.
```

## Extended search planning

```{figure} esp-cycle.svg
:name: fig-esp-cycle
:alt: Steps 1 to 7 run once, from reviewing the initial response to weighting the segments. Steps 8 to 11, task, debrief, recalculate and re-task, then repeat as a loop.

Steps 1–7 set up the search; steps 8–11 repeat ({doc}`CON-16 </part-3/3-1-concepts/con-16-esp-process>`, {doc}`PRC-02 </part-3/3-4-processes/prc-02-extended-search>`).
```
