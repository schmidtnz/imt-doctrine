# PRC-02 Extended search planning cycle

| Step | Do | Output |
|---|---|---|
| 1 | Review the initial response | Map of effort, clues, gaps |
| 2 | Determine the search area | Refined search area boundary |
| 3 | Develop scenarios | Scenario recording sheets |
| 4 | Mark regions | 6–10 scenario and geographical regions |
| 5 | Weight regions | {doc}`Scenario weighting sheet </forms/frm-02-scenario-weighting>` |
| 6 | Segment top regions | Segments sized for 4–6 hour tasks |
| 7 | Weight segments | Segment POA |
| 8 | Task highest segments | Tasking sheets |
| 9 | Debrief | {doc}`Team debrief </forms/frm-01-team-debrief>` with POD |
| 10 | Recalculate | Updated segment POA |
| 11 | Re-task | Next IAP |

Repeat steps 8–11 until the high-POA segments are searched to the IMT's satisfaction.
