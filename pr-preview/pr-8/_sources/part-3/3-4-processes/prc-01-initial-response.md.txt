# PRC-01 Initial response (MMISSI TD)

| Step | Do | Output |
|---|---|---|
| 1 | Complete or update the missing person report | MPR, LPB category |
| 2 | Map and terrain analysis | Planning map with planning points, rings, route, hazards |
| 3 | Information collection plan | Assigned enquiries, updated profile |
| 4 | Initial scenarios | Ranked scenarios tied to terrain |
| 5 | Confirm search urgency | Search urgency form, go/no-go |
| 6 | Incident action plan | IAP with Bike Wheel objectives |
| 7 | Task | Tasking sheets, briefing |
| 8 | Debrief | {doc}`Team debrief </forms/frm-01-team-debrief>` with POD |

Repeat steps 6–8 until the initial response objectives are met, then start {doc}`prc-02-extended-search`.
